# 사회교육관 디지털 안전지도 시제품

- 왼쪽 3~8층 버튼으로 층 전환
- 파란 완강기 버튼 클릭 시 상세정보 팝업
- 8층을 실제 시연용으로 구성
- 실제 제작 단계에서는 각 층 SVG를 CAD 기반 SVG로 교체
- `deviceInfo`의 사진/설치일/관리일/점검일/하강시간/적정하중을 실제 자료로 교체

## GitHub Pages
1. GitHub에 새 저장소를 만듭니다.
2. `index.html`을 업로드합니다.
3. Settings → Pages → Deploy from a branch → main / root 선택
4. 생성된 `https://아이디.github.io/저장소명/` 주소를 QR에 넣습니다.
